# S87 老戰友回城 — HTML 互動廣告（Playable Ad）

主打**回流老玩家**的情感路線。玩家親手把一座蒙塵的荒城點亮成城，名將一個個歸隊。

## 為什麼做這支

Meta 前 10 名靜態素材裡，`我在霸王之業等你` CTR 1.66 且是唯一被標註裝率的（3.78）—— **情感／陪伴訴求的裝率優於純美術主視覺**。而 2026-08 整檔文案打的就是回流（老戰友再戰一局、九年了換你掌局、回歸就送、回來正是時候）。

「回歸」這個角度**靜態圖做不到**：靜態圖只能喊「回來吧」，playable 可以讓人**親手把城點亮**。這是唯一一支「互動形式本身就是訴求」的概念——其他玩法換成影片也成立，這支不行。

## 玩法流程（策略三階段）

### UI 架構（比照官方遊戲介面）

參考 `遊戲截圖_官方` 的三張真實 UI（內城城池／名將錄／世界地圖攻城），把介面語言搬進來：

| 區塊 | 內容 |
|---|---|
| 頂部資源列 | 木材／鐵礦／兵力三格，各有圖示框、現有量、**每秒產量**；不足時邊框閃紅 |
| 階段列 | 金色階段標籤（營建／謀略／出征）+ 階段說明 + 進度數字 + 進度條 |
| 左右龍柱 | 仿遊戲畫面兩側的金色龍柱裝飾 |
| 右側圓鈕 | 軍師／名將／福利三顆圓形金框鈕，該按時發光＋紅點 |
| 底部導覽 | 內城／名將／謀略／軍務／世界五個頁籤，當前頁籤高亮，階段推進時自動切換 |
| 名將卡 | 仿名將錄的**金框卡片**：星等、頭像、名牌、加成說明；未歸隊時暗版並顯示「未歸隊」 |

側邊鈕與導覽頁籤**不做假功能**——點下去給的是當前該做什麼的引導吐司（例如「先把城立起來，再議謀略」），不會出現點了沒反應或假畫面。

### ① 開場鉤子（0~4.2 秒，點擊可跳過）
荒城為底、關羽全黑剪影帶金邊呼吸掃光，大字「主公，**九年**了。這座城等你來立。」

### ② 營建期：資源經濟
六處建築各有**資源成本**，成本標在工地下方（不足的那項變紅）。資源不足時工地變暗、光圈停止、成本標紅；足夠時光圈脈動＋核心呼吸＋亮**紅點**。

| 建築 | 木材 | 鐵礦 | 兵力 | 完成後每秒產量 |
|---|---|---|---|---|
| 工 坊 | 60 | 20 | — | 木材 +4 |
| 馬 廄 | 90 | 50 | — | 兵力 +3 |
| 兵 營 | 140 | 90 | 40 | 兵力 +5 |
| 集賢府 | 200 | 140 | 60 | 木 +3 ‧ 鐵 +3 ‧ 兵 +2 |
| 計謀房 | 280 | 220 | 100 | 鐵礦 +6 |
| 宮 城 | 420 | 340 | 180 | 木 +5 ‧ 鐵 +5 ‧ 兵 +4 |

- 起始每秒 木 3／鐵 2／兵 2，**蓋得越多累積越快**（全蓋完基礎值為 木 15／鐵 16／兵 16，再乘名將加成）
- 地圖上隨機冒出**採集節點**（木／鐵／兵），點掉即得資源；單次採集量隨已建數量成長（`(10~20) × (1 + 已建×0.5)`）
- 每建兩處迎回一位名將，並獲得**乘算加成**：

| 名將 | 觸發 | 加成 |
|---|---|---|
| 關 羽 | 建滿 2 處 | 兵力產出 ×1.5 |
| 諸葛亮 | 建滿 4 處 | 木材與鐵礦產出 ×1.4 |
| 皇甫嵩 | 建滿 6 處 | 全產出 ×1.3 |

三將全歸位後總乘算：木鐵 ×1.82、兵力 ×1.95。

### ③ 謀略期：出謀劃策（三國情境二選一）
六處建完後軍師鈕發光、謀略頁籤亮紅點，跳出**軍師諫言**面板（諸葛亮頭像＋情境＋兩個選項）：

| 情境 | 上策 | 下策 |
|---|---|---|
| 敵軍屯糧於烏巢，守備鬆懈 | 遣輕騎夜襲，焚其糧草 → 兵 +150 木 +80 鐵 +60 | 正面壓上，強攻其營 → 兵 +60 木 +20 鐵 +20 |
| 江東連日大霧，敵船以鐵索相連 | 借風勢以火船焚之 → 兵 +180 鐵 +120 木 +60 | 遣使議和，暫避鋒芒 → 兵 +70 木 +30 鐵 +30 |
| 洛陽城高糧足，久攻不下 | 圍城斷援，待其自亂 → 兵 +220 木 +100 鐵 +100 | 全軍猛攻，速戰速決 → 兵 +80 木 +40 鐵 +40 |

選完立刻給「**上策／下策**」判定與軍師評語。**下策不懲罰**，只是獎勵較少——廣告不該讓玩家挫敗，但要讓「想對了比較賺」。

### ④ 出征期
出征鈕出現，消耗 **兵力 600**（兵力不夠時變灰並顯示還差多少）。點下去 → 金光爆閃 + 「大軍出征」橫幅 → 結束卡。

### ⑤ 結束卡
Logo + 「老戰友，**再戰一局**」+ S87 8/26 新服加開 + 三格資訊 + CTA「立即下載」+ 雙平台標章

## 手感細節

- 名將歸隊動畫（1.35 秒）期間點工地不會靜默無反應：跳吐司「名將歸隊中 ‧ 稍候即建」，並把那一下**記下來，動畫結束自動補建**
- 資源增加時對應的資源格會彈一下；不足時邊框閃紅兩次
- 建築完成先飄「工坊已成」，0.26 秒後再飄「木材 +4 / 秒」，讓因果看得清楚

## 投放注意

- CTA 通用相容：`FbPlayableAd.onCTAClick()` → `ExitApi.exit()` → `mraid.open()` → `dapi.openStoreUrl()` → 開新視窗
- `STORE_URL` 為 Google Play：`com.userjoy.rte`
- 舞台固定 720×1280，transform scale 等比置中
- 沒操作時 4.2 秒自動離開鉤子畫面，不會卡在開場
- `Element.prototype.animate` 不存在的舊 WebView 會自動略過金屑粒子，其餘表現不受影響
- 遮罩用 `-webkit-mask-image` + `mask-image` 雙寫；極舊 WebView 不支援時修復區塊會是硬邊圓形，仍可辨識

## 打包踩過的坑

同一張圖被內嵌多次會讓檔案爆掉——第一版關羽嵌 3 次、城池 2 次、Logo 2 次，檔案 **2.22 MB**（超過 Meta 上限）。已改成：CSS 背景走 `:root` 的 `var(--cityFull)`，`<img>` 走 `#ASSETS` 的 `data-*` 加開頭一段 JS 指派 `src`，同一份素材只嵌一次 → **1.26 MB**。
