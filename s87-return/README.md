# S87 老戰友回城 — HTML 互動廣告（Playable Ad）

主打**回流老玩家**的情感路線。玩家親手把一座蒙塵的荒城點回顏色，名將一個個歸隊。

## 為什麼做這支

Meta 前 10 名靜態素材裡，`我在霸王之業等你` CTR 1.66 且是唯一被標註裝率的（3.78）—— **情感／陪伴訴求的裝率優於純美術主視覺**。而 2026-08 整檔文案打的就是回流（老戰友再戰一局、九年了換你掌局、回歸就送、回來正是時候）。

「回歸」這個角度**靜態圖做不到**：靜態圖只能喊「回來吧」，playable 可以讓人**親手把城點亮**。這是唯一一支「互動形式本身就是訴求」的概念——其他玩法換成影片也成立，這支不行。

## 玩法流程

**① 開場鉤子（0~4.2 秒，點擊可跳過）**
- 荒城為底，關羽**全黑剪影**（`filter:brightness(0)`）+ 金色外光暈，另疊一層 `mix-blend-mode:screen` 的邊光做呼吸掃光
- 大字「主公，這座城等了你**九年**。」／副標「你的名將，一個都沒走。」
- 解決「前 3 秒偏暗會掉留存」的風險：剪影帶金邊 + 金色字 + 呼吸光，暗場但有亮點

**② 修復城池**
- 六處真實建築名稱（宮城／兵營／集賢府／馬廄／工坊／計謀房）各有脈動光圈，**每處點 3 下**（共 18 次點擊）
- 點擊有金屑迸散；修好時爆光圈 + 飄字「宮城已復」
- 該處的城池**恢復顏色**：一個 360×360 的 `.patch`，背景是完好版城池圖並用 `background-position` 對位，加 `radial-gradient` 圓形遮罩，所以是「這一塊亮回來」而不是整張切換
- 同時全域的廢墟蒙層隨進度變淡（1 → 0.65 → 0.475 → 0.3 → 0.125 → 0），蒙塵微粒也跟著消失

**③ 名將歸隊（每修 2 處觸發 1 位）**
- 剪影狀態滑入隊列 → 0.42 秒後**亮起**（`brightness(0)` 解除 + 金色外光）+ 白光爆閃
- 說一句台詞：
  - 關羽「主公一聲令下，關某即刻回營。」
  - 諸葛亮「亮已備好方略，只待主公點兵。」
  - 皇甫嵩「老夫的兵，一直沒散。」

**④ 完成 → 結束卡**
- 橫幅「城池已復 ‧ 三將歸位 ‧ 只等主公」
- 2 秒後結束卡：Logo + 「你的城與名將，**都為你保留著**」+ S87 8/26 開服 + 三個回歸禮包（7 日名將試用／玄關羽免費領／回歸禮包登入即送）+ CTA「回歸領獎」+ 雙平台標章

節奏約 20~25 秒（比 `s87-guanyu` 的 38~52 秒短，刻意壓短以拉高完玩率）。

## 投放注意

- CTA 通用相容：`FbPlayableAd.onCTAClick()` → `ExitApi.exit()` → `mraid.open()` → `dapi.openStoreUrl()` → 開新視窗
- `STORE_URL` 為 Google Play：`com.userjoy.rte`
- 舞台固定 720×1280，transform scale 等比置中
- 沒操作時 4.2 秒自動離開鉤子畫面，不會卡在開場
- `Element.prototype.animate` 不存在的舊 WebView 會自動略過金屑粒子，其餘表現不受影響
- 遮罩用 `-webkit-mask-image` + `mask-image` 雙寫；極舊 WebView 不支援時修復區塊會是硬邊圓形，仍可辨識

## 打包踩過的坑

同一張圖被內嵌多次會讓檔案爆掉——第一版關羽嵌 3 次、城池 2 次、Logo 2 次，檔案 **2.22 MB**（超過 Meta 上限）。已改成：CSS 背景走 `:root` 的 `var(--cityFull)`，`<img>` 走 `#ASSETS` 的 `data-*` 加開頭一段 JS 指派 `src`，同一份素材只嵌一次 → **1.26 MB**。
