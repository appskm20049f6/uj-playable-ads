# 群英烙餅攤（Heroes' Flatbread Stall）

三國群英傳 覺醒（Kingdom Heroes Awakening）的 60 秒網頁小遊戲。

- 玩法：武將到窗口點餅，照訂單點配料（蔥、芝麻、牛肉、香菜、辣醬），數量要剛好，按「烤」出餅。做對拿金幣，剩餘耐心與連擊越高金幣越多；做錯或讓客人等太久連擊歸零。
- 出題武將固定循環：馬超 → 諸葛亮 → 趙雲 → 司馬懿 → 呂布 → 曹操。
- 每局 60 秒，結算後輸入名字登錄前十名排行榜。排行榜存在瀏覽器 localStorage，各裝置各自一份。
- 鍵盤操作：`1`–`5` 放配料（蔥、芝麻、牛肉、香菜、辣醬）、`空白鍵` 烤、`R` 重做；滑鼠與觸控照常可用。
- 右上角可切換中文／英文與音效。橫式舞台 1280×720（`index.html`），直式舞台 720×1280（`portrait.html`），等比縮放置中。

## 結構

```
index.html      橫式版
portrait.html   直式版（同一份程式，只差版面）
                兩個都是單一檔案：背景與六位武將 Q 版圖以 base64 內嵌，
                配料、餅、烤爐以 canvas / CSS 繪製，離線可開
```

這支是網頁小遊戲，沒有 CTA 與 AppsFlyer 連結，不能直接上傳投放。
