# 群英烙餅攤（Heroes' Flatbread Stall）

三國群英傳 覺醒（Kingdom Heroes Awakening）的 60 秒網頁小遊戲。

## 玩法

- 一次來三位武將，各有一張訂單和耐心條。照任一張訂單放配料、數量要剛好，按「烤」，餅會自動送給訂單相符的武將（多人相符時給最急的那位）。沒有人點的餅算做錯。
- 出場順序固定循環：馬超 → 諸葛亮 → 趙雲 → 司馬懿 → 呂布 → 曹操。
- 表情三階段：耐心 55% 以上笑臉、28%～55% 開始急、28% 以下臭臉；等到耐心歸零就走人。
- 做錯或有人走掉：扣 3 秒、連擊歸零（FEVER 期間不扣時間）。

## 追加機制

| 機制 | 條件 | 效果 |
|---|---|---|
| FEVER TIME | 連續做對 5 次（集滿五顆火） | 7 秒內分數 ×2、倒數計時暫停，畫面發光 |
| 三選一獎勵 | 連擊每滿 10 | 加時間 +10 秒／加分數 +150／追加食材（煎蛋、香菇；都解鎖後改為全食材升一級） |
| 食材升級 | 同一種食材累計用 4 份、10 份 | 升 ★★、★★★，每份多 3、6 金幣 |
| 成功演出 | 每次做對 | 中央成功文字、煙火、武將專屬特效，爐火隨連擊變旺 |

計分：基本 10 ＋ 剩餘耐心加成（最多 10）＋ 各食材單價 × 份數，再乘連擊倍率（每連擊 +10%，上限 +100%）與 FEVER ×2。

## 操作

- 滑鼠／觸控：點配料盤、烤、重做。
- 鍵盤：數字鍵放配料（依配料盤順序，追加食材後是 6、7）、`空白鍵` 烤、`R` 重做；三選一時按 `1` `2` `3`。
- 右上角可切換中文／英文與音效。
- 每局 60 秒，結算後輸入名字登錄前十名排行榜。排行榜存在瀏覽器 localStorage，各裝置各自一份。
