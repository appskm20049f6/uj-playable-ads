## 玩法設計

- **庫銀自動累積**：起始 100 金、每秒 +14，數字每 0.1 秒刷新（看得到跳動）
- **開場點擊引導**：關羽身上有脈動光圈＋手指圖示＋「點我催糧！」，第一次點擊後自動收掉
- **COMBO 連點**：1.6 秒內連點累積 combo，右側大數字跳動
  - 產金速度倍率 `×(1 + combo×0.12)`，上限 **×4.6**（HUD 的每秒產量會變金色並顯示倍率）
  - 單次點擊收益 `×(1 + combo×0.18)`，上限 **×6.4**
  - 戰鬥動畫期間 **凍結** combo 不歸零，結算後接回計時
- **出戰**（主按鈕）：扣金幣 → **金光爆閃 + 放射光芒 + 18 顆金屑四散** + 刀光 + 震屏 → 「大勝／敗退」面板
- **守城**：徵繳稅賦，一次拿到 14 秒產量 + 戰力，6 秒冷卻
- **強化**：礪刀，戰力 +14%、**收金速度 +12%**，成本每次遞增
  - 提示兩層：按鈕副標直接寫 **「收金 +12% ‧ N 金」**（+12% 用金色標出）、金幣夠時按鈕**發光脈動**
  - 按下後飄字顯示「收金 +12% ‧ 每秒 17」，關羽台詞也會講「甲堅兵利，此後收金更快」
  - 註：原本做過浮在按鈕上方的紅底小標籤，但 `.sub` 有 `overflow:hidden` 會把它裁進按鈕內壓住「強化」字，已改為併入副標
- **晉升官階**：每 2 勝晉一階，庫銀增速 **×1.7**，最高 5 階（封頂避免橫幅洗版）
- **結束卡（廣告頁）**：**軍資達 30,000 金**自動彈出 → Logo + S87 8/26 開服 + 立即預約 + 雙平台標章
  - 保險機制：若玩家完全不操作，**75 秒**也會強制進廣告頁
  - HUD 的進度條就是軍資目標條（`軍資 x / 30,000`），玩家看得到終點

**節奏實測**（同一套公式模擬）：積極玩 ~46 秒、一般玩 ~52 秒、只掛機不點 ~121 秒（會被 75 秒保險提前結束）。
勝率為前兩場必勝、之後約 72% 且**不連敗**，避免卡關。

## 投放注意

- CTA 走通用相容寫法，依序嘗試 `FbPlayableAd.onCTAClick()`（Meta）→ `ExitApi.exit()`（Google）→ `mraid.open()` → `dapi.openStoreUrl()` → 開新視窗
- 未跑在廣告容器時會開 `STORE_URL`（現為 Google Play：`https://play.google.com/store/apps/details?id=com.userjoy.rte&hl=zh_TW`）
- 舞台固定 720×1280（9:16），用 transform scale 等比置中，直式手機滿版、橫式也不會破版
- 結束卡整片可點，另有「立即預約」大按鈕
