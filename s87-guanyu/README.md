## 檔案

| 檔案 | 說明 |
|---|---|
| `S87_關羽爭霸_playable.html` | **成品**。單一檔案、素材全部 base64 內嵌、1.18 MB，離線可跑（Meta 上限 2 MB／Google 5 MB 內） |

改完 `src/template.html` 後重新打包：

```bash
python build.py
```

## 玩法設計

- **庫銀自動累積**：起始 80 金、每秒 +12，數字每 0.1 秒刷新（看得到跳動）
- **點擊關羽**：立即 +金幣，有飄字與角色回饋動作
- **出戰**（主按鈕）：扣金幣 → 刀光／閃白／震屏 → 跳出「大勝／敗退」面板，勝場累積戰功
- **守城**：徵繳稅賦，一次拿到 8 秒產量 + 戰力，6 秒冷卻
- **強化**：礪刀，戰力 +14%、產金速度 +12%，成本每次遞增
- **晉升官階**：每 2 勝晉一階，庫銀增速 **×1.6**，橫幅 + 光環爆發
- **結束卡**：升到官階 Lv.4（或打滿 12 場）自動進入 → Logo + S87 8/26 開服 + 立即預約 + 雙平台標章

節奏：從開場到結束卡約 40～60 秒，勝率設計為前兩場必勝、之後約 72% 且**不連敗**，避免卡關。

## 台詞

全部走三國口吻、以「主公」稱呼玩家，分 idle／點擊／出戰／勝／敗／守城／強化／缺錢／晉階／結束共 10 組，逐字打字機顯示、閒置 5.2 秒換一句。要改台詞找 `src/template.html` 裡的 `var LINES={...}`。

## 投放注意

- CTA 走通用相容寫法，依序嘗試 `FbPlayableAd.onCTAClick()`（Meta）→ `ExitApi.exit()`（Google）→ `mraid.open()` → `dapi.openStoreUrl()` → 開新視窗
- 未跑在廣告容器時會開 `STORE_URL`（現為 `https://sanguo.uj.com.tw/`），要換官網／商店連結改這個變數
- 舞台固定 720×1280（9:16），用 transform scale 等比置中，直式手機滿版、橫式也不會破版
- 結束卡整片可點，另有「立即預約」大按鈕
